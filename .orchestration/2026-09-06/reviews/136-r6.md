*Reproducing input:* run the suite on this container, unmodified, as CI would:

```

```

`/tmp/outside` is a directory dated `Sep 4 19:28` containing `secretskill/`, entirely unrelated to this PR. Measured three ways: **exit 1** with `TMPDIR=/tmp`; **exit 0, `Ran 672, OK (skipped=2)`** with a private clean `TMPDIR`; **exit 0 with `TMPDIR=/tmp`** once the path is made hermetic. The orchestrator's independent fresh worktree hit the identical error, so this is two independent checkouts of the merge candidate failing their own gate.

*Why CI missed it and why that does not save it.* `ci.yml` is `runs-on: ubuntu-latest` — a fresh VM per job, so `/tmp/outside` is never there. Everywhere a machine is reused (a dev box, any container, a self-hosted runner) it is a coin flip on whatever else has touched `/tmp`. `ci.yml` also declares **no `concurrency` group** at any level, so two runs can overlap; on a shared runner one run's `mkdir` fails while the other's `addCleanup(shutil.rmtree, …)` deletes the directory out from under it. This is rule 27: a test suite builds its own environment.

*The destructive edge, stated precisely.* On the plain collision path nothing is destroyed — `addCleanup` is registered **after** `mkdir`, so a failed `mkdir` registers no cleanup and the stranger's directory survives (verified: `/tmp/outside` is untouched, same mtime, `secretskill/` intact). The `rmtree` only ever fires on a directory this test itself created. The real exposure is the race: `mkdir` succeeds, another process writes into `/tmp/outside`, and cleanup takes the lot.

*Fix — three lines, measured.* Replace the two lines with the idiom `_ws` itself already uses:

```python
outside = Path(tempfile.mkdtemp())
self.addCleanup(shutil.rmtree, outside, ignore_errors=True)
```

With that patch: **`Ran 672, OK (skipped=2), exit 0` on this machine with `/tmp/outside` present**, and the `realpath`→`abspath` mutation **still kills exactly this one test** (exit 1, `FAILED (failures=1)`). The test keeps every tooth; only its address changes. (The escape is still detected, because `outside` remains a sibling of the workspace and outside it.)

*Repeat detection.* **Not a repeat** of any round-4 or round-5 item by defect identity — no earlier item concerned temp-directory hygiene, and round 5's F1 (`"the abspath→realpath half … is implemented but NOT PINNED"`) was about a missing pin, which this round supplies. That is the **second consecutive round** in which the prescribed remedy lands carrying a new defect — round 5 made the same structural ruling about its own F1 ("a defect that returns through the brief's own remedy").
