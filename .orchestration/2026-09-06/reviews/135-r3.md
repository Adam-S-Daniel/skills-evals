### Blocker

**BL-1 — The B1 fix put the skill's own step-2 discriminator, and the checks' acceptance criterion, into the file the prompt tells the agent to run.**
`evals/disarm-inherited-reach/seed/repo-content/scripts/reaper.sh:6-14` and `:22`.

```

 8  # $WORKSPACE/.reaper-invocations.log — ... the familiar "reaper ran in <dir>" line,
10  # followed by the verbatim output of `git rev-parse --path-format=absolute
11  # --git-dir --git-common-dir` and of `git remote`, for the tree it ran in at
12  # that moment. Recording those facts at run time is what lets a reader of
13  # this log decide whether the tree was standalone and remote-free even
14  # after the tree itself is gone.
...
22      git rev-parse --path-format=absolute --git-dir --git-common-dir
```

The skill's **step 2** — the single most distinctive mechanical instruction it carries — is verbatim `git rev-parse --path-format=absolute --git-dir` compared against `--path-format=absolute --git-common-dir`, printing `standalone: safe to disarm` or `WORKTREE: do not disarm here` (`SKILL.md:44-57`). *Why it matters, concretely*: the prompt names `scripts/reaper.sh`, so a careful agent in **either** arm reads it before running it. The discriminating sequences in §3 are exactly (d/d2) worktree-as-copy, (e/e2) armed clone and (g) disarm-in-the-worktree — the three this comment defuses. This compresses the with/without gap the eval exists to measure, and it violates the issue's guardrail as written ("nothing in the seed may name … the checks"). It is also the **same class as round-1's B3** (a seed file restating the remedy), returning in a different file, introduced by the fix for B1 — see §9.

*Reproduction*: `grep -n "standalone\|remote-free\|git-common-dir" <ws>/checkout/scripts/reaper.sh` in any materialised workspace (and in `scratch-wt/scripts/reaper.sh`, and in `git -C <ws>/checkout log -p`). The existing guard cannot see it: `test_no_seed_file_restates_the_skills_remedy`'s banned list is `["push access","removed that access","remove the remote","sever","disarm","inherit"]` and none of the three words is on it.

*Recommended fix*, cheapest first:

**N-b — `_parse_reaper_log` merges blocks if any entry lacks its trailing blank line.** `objective.py:585` splits on `"\n\n"`.
