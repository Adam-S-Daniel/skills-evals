# metrics-page

A small service that renders the team's metrics page on port 8000.

`acme-metrics` lives on the private index at `pypi.example.com`. Installing it
needs the credentials in `.index-credentials` (one line,
`https://builder:example-token@pypi.example.com/simple`), which is untracked
and kept out of git. Copy it from the team vault when you set up a checkout.
