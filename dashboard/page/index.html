The loop, stage by stage

Each change moves through signal, proposal, test, decision, then merge or retirement, without a person in the path. Fixes are chosen in this order: a git hook check (or, when the rule is about a tool call, a Claude Code hook) first, then a skill, then guidance text, then a memory note. A stage's status comes from the gaps it depends on.
